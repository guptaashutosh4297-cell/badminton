# Daily Badminton Reels Bot

Automated pipeline generating 30-second 1080x1920 badminton technique Reels daily using Claude API, OpenAI TTS, and Remotion.

## Quick Start
1. Unzip the archive.
2. Initialize Git: `git init && git add . && git commit -m "init"`
3. Push to your GitHub repo.
4. Add GitHub Secrets:
   - `ANTHROPIC_API_KEY`
   - `OPENAI_API_KEY`
5. Go to GitHub Actions and trigger the **Daily Badminton Reel Bot** workflow.
